## 2025-02-24 - CSV Formula Injection via Carriage Return (\r) trigger
**Vulnerability:** A CSV Formula Injection vulnerability was discovered in `ReservationExporter.java`. The code correctly checked for standard triggers (`=`, `+`, `-`, `@`, `\t`) after trimming leading whitespace. However, it failed to recognize that carriage return (`\r`) is itself a dangerous formula trigger in certain spreadsheet applications. Because `\r` was treated as normal whitespace by `Character.isWhitespace()`, a payload starting directly with the unrecognized trigger followed by normal text (e.g., `\rcmd`) would bypass the protection entirely, as the trimming logic would skip the `\r` and find `c` (a non-trigger).

**Learning:** When manually trimming whitespace to detect CSV Formula Injection triggers, do not use `Character.isWhitespace()` blindly, as it returns true for Tab (`\t`) and Carriage Return (`\r`), which are dangerous formula triggers themselves. When verifying protections for missed trigger characters (like `\r`), test payloads must start directly with the unrecognized trigger followed by normal text (e.g., `\rcmd`), rather than combining it with an already-recognized trigger (e.g., `\r=cmd`). The latter may produce false positives because existing whitespace trimming logic might coincidentally skip the unrecognized character and correctly escape the subsequent recognized trigger.

**Prevention:** Explicitly exclude `\t` and `\r` from the trimming condition so they can be properly escaped. Ensure that manual CSV escaping logic explicitly adds `\r` to the list of trigger characters.
