## 2025-02-18 - CSV Injection bypass via unhandled tab trigger after whitespace
**Vulnerability:** A CSV Formula Injection vulnerability in `ReservationExporter` was bypassing protections. While the code escaped trigger characters (like `=`, `+`, `-`, `@`) appearing at the start of a field after trimming leading whitespace, it failed to properly classify the tab character (`\t`) as a trigger character if it followed leading whitespace. Spreadsheet software ignores leading whitespace and will evaluate `\t=cmd` as a formula.
**Learning:** `Character.isWhitespace(c)` and `Character.isSpaceChar(c)` return true for spaces and newlines, but not all triggers are simple symbols. The tab character itself can act as a formula injection trigger in some spreadsheet engines or can be part of an exploit string. When checking for injection triggers after stripping whitespace, the tab character must be explicitly accounted for both as something to *not* trim and something to treat as a trigger character itself.
**Prevention:** Explicitly exclude `\t` from whitespace trimming loops (e.g. `c != '\t' && Character.isWhitespace(c)`) and explicitly include `\t` in the list of characters that trigger quoting (e.g. `firstNonWs == '\t'`).
