## 2026-08-28 - CSV Injection Protection Fix
**Vulnerability:** The CSV export functionality was vulnerable to Formula Injection via Carriage Return (`\r`). The `isSpreadsheetTrimmable` function was correctly catching spaces and standard whitespace, but explicitly excluded tab characters. The checking for the first non-whitespace character in `escapeCsvField` missed checking for carriage return `\r` as a potential formula trigger. Although `\r` behaves like whitespace in trimming in Excel, if a cell evaluates to a `\r` followed by a command (like `=cmd`), some implementations can still process the command. Thus, `\r` needs to be considered a formula prefix trigger or whitespace to skip.

**Learning:** Spreadsheet programs like Excel trim various types of whitespace before evaluating if a cell begins with a formula trigger (like `=`, `+`, `-`, `@`). While the existing logic explicitly avoided treating tab `\t` as ignorable whitespace and rightly treated it as a trigger, it neglected `\r`. Carriage returns must also be treated as a trigger since spreadsheet parsers might evaluate formulas starting with it after stripping it or processing it minimally.

**Prevention:** Ensure that when writing logic to prepend single quotes (`'`) to escape CSV formula injection, all known whitespace and formula trigger characters are comprehensively handled. Carriage return (`\r`) must be added to the list of triggers.
