## 2026-09-07 - Fix CSV Formula Injection missing carriage return trigger
**Vulnerability:** The CSV exporter was checking for formula injection by trimming whitespace and then checking the first character. However, it used a custom `isSpreadsheetTrimmable` function that missed carriage return (`\r`), allowing a payload like `\rcmd` to bypass the prefix logic while still executing as a formula when opened in some spreadsheet applications.
**Learning:** `\r` and `\t` are both characters that spreadsheet applications will skip/trim when parsing a cell before looking for a formula trigger (`=`, `+`, `-`, `@`). Trimming functions in the backend need to carefully exclude these non-standard space characters so that the subsequent logic correctly prepends the single-quote (`'`) escape character.
**Prevention:** Always maintain a strict and comprehensive definition of space characters when manually checking for CSV formula injection. Exclude characters like `\r` and `\t` from standard trim logic if they act as formula triggers, and explicitly check for them as triggers before deciding whether to escape the cell value.
