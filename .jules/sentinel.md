## 2026-09-11 - CSV Injection Vulnerability Fix
**Vulnerability:** Found a CSV injection vulnerability in `ReservationExporter.java` where a payload starting with a carriage return (`\r`) character could bypass the escaping logic. This is because carriage returns were not excluded from the whitespace trimming when determining formula triggers, allowing malicious users to execute arbitrary commands by prepending a carriage return to Excel formulas.
**Learning:** When mitigating CSV injection vulnerabilities, all variations of characters trimmed by spreadsheet applications must be correctly identified and evaluated. Specifically, tab (`\t`) and carriage return (`\r`) should be treated differently as they can serve to evade naive prefix checks.
**Prevention:** Explicitly exclude `\r` (alongside `\t`) from the `isSpreadsheetTrimmable` character check, and add `\r` to the list of formula trigger characters that receive a prepended single quote (`'`). Always ensure complete sanitization of formula triggers, including those with evasion prefix characters like tabs or carriage returns.
