## 2026-09-09 - CSV Formula Injection triggers (Carriage Return)
**Vulnerability:** The CSV exporter failed to correctly escape fields starting with a Carriage Return (`\r`). This can be exploited for CSV injection, as spreadsheet software like Excel may interpret `\r` followed by formula characters as executable code, bypassing whitespace-trimming-based protections.
**Learning:** When sanitizing fields for CSV formula injection by stripping leading whitespace, characters like `\t` and `\r` must be explicitly excluded from whitespace trimming functions like `Character.isWhitespace()`. `\t` and `\r` can themselves act as triggers or bypasses and must be checked explicitly after standard whitespace is trimmed. Test cases must ensure they test for the trigger directly following the unrecognized trigger character.
**Prevention:** Always comprehensively consult spreadsheet software behavior for formula execution triggers. Explicitly exclude characters like `\t` and `\r` from `isSpreadsheetTrimmable` checks and directly check for them as potential triggers for formula injection.
